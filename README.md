## Problem Statement

Energy-intensive manufacturing plants such as steel plants operate large electrical loads whose consumption varies significantly with production schedules, time of day, and operating conditions, resulting in higher energy costs and inefficient load utilization. This project aims to develop an energy-aware production scheduling system that forecasts short-horizon electricity load behavior, classifies load conditions, and uses the forecasts to determine the cost-optimal timing of production activities. Using 15-minute steel-plant metering data, the system will clean and transform the data, perform exploratory and statistical analysis, engineer time-series and operational features, build machine-learning-based load forecasts and load-type classification models, and feed the predictions into a Mixed-Integer Linear Programming (MILP) optimization model. The optimizer will schedule production across available time blocks while satisfying production quotas, machine capacity, and power-factor constraints, with scenario analysis used to evaluate the impact of tariff changes, capacity restrictions, increased production requirements, and tighter power-factor penalties. The final solution will be presented through a Streamlit dashboard comparing actual and forecasted loads, optimized and naive production schedules, and the resulting energy-cost savings.
